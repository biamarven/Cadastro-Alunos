Sistema de Cadastro de Alunos

Projeto acadêmico desenvolvido para a A3 (Avaliação 3) do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é desenvolver um sistema para facilitar o cadastro e o gerenciamento de alunos, cursos, notas e históricos acadêmicos.

Objetivo do Projeto

Desenvolver uma solução que permita organizar informações acadêmicas de maneira simples, segura e eficiente, aplicando conceitos de análise, modelagem e desenvolvimento de sistemas.

Funcionalidades

Cadastro e gerenciamento de alunos.

Gestão de cursos.

Registro e consulta de notas.

Consulta do histórico acadêmico.

 Requisitos Não Funcionais

Segurança: proteção e integridade dos dados cadastrados.

Desempenho: execução eficiente das operações do sistema.

Usabilidade: interface simples e intuitiva.

 Modelagem e Documentação

Durante o desenvolvimento, serão elaborados os seguintes artefatos:

UML: diagramas de casos de uso, classes e sequência.

BPMN: modelagem dos processos de cadastro e gestão de alunos.

Prototipação: criação das interfaces no Figma.

Testes: testes unitários, de integração e de usabilidade.

 Tecnologias

As tecnologias utilizadas serão definidas e documentadas conforme o andamento do projeto.

 Status do Projeto

Em desenvolvimento — etapa inicial de planejamento e estruturação.

Equipe

Projeto desenvolvido em grupo para fins acadêmicos.
